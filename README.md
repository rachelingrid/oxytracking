# oxytracking
Rastreio oximétrico noturno executável no navegador, sem dependências e sem rede. Calcula ODI, carga hipoxêmica, índices de escala lenta da frequência de pulso, PSD de Welch e coerência espectral; emite relatório com critérios de disparo declarados. Triagem, não diagnóstico. Direitos reservados.
